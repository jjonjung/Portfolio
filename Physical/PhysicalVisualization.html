Part 1: AABB 바운딩 박스 시스템

Axis-Aligned Bounding Box Coordinate Transformation

📐

AABB 바운딩 박스 계산

AABB Bounding Box Calculation

UBoxComponent (반투명 주황색)

핵심 수식

Min = Origin - Extent
Max = Origin + Extent

함수명

GetXYBounds()

설명

AABB (Axis-Aligned Bounding Box)는 객체를 감싸는 축 정렬 경계 상자입니다. Origin(중심점)과 Extent(반경)를 사용하여 Min과 Max 좌표를 계산합니다.

🗺️

UV (0~1) → 월드 XY 좌표

UV to World XY Transformation

UV 공간에서 월드 공간으로의 선형 보간

핵심 수식

WorldXY = Lerp(Min, Max, ClampedUV) X = Min.X + (Max.X - Min.X) × UV.X
Y = Min.Y + (Max.Y - Min.Y) × UV.Y

함수명

UVToWorldXY()

설명

정규화된 UV 좌표(0~1)를 실제 월드 공간의 XY 좌표로 변환합니다. FMath::Lerp를 사용하여 바운딩 박스의 Min과 Max 사이를 선형 보간합니다.

사용 예시

// UV (0.5, 0.5) → 월드 중심점
FVector2D worldPos =
  UVToWorldXY(0.5f, 0.5f);
🎚️

월드 XY → UV (0~1)

World XY to UV Transformation

월드 공간에서 UV 공간으로의 범위 매핑

핵심 수식

UV = MapRangeClamped(Min, Max, 0, 1, WorldXY) U = (WorldX - Min.X) / (Max.X - Min.X)
V = (WorldY - Min.Y) / (Max.Y - Min.Y)

함수명

WorldXYToUV()

설명

월드 공간의 XY 좌표를 정규화된 UV 좌표(0~1)로 역변환합니다. FMath::GetMappedRangeValueClamped를 사용하여 바운딩 박스 내에서의 상대적 위치를 계산합니다.

사용 예시

// 플레이어 위치 → 미니맵 UV
FVector2D uv =
  WorldXYToUV(PlayerLocation);

❌ 문제: 오차 누적으로 로프 길이 증가

🎯 최종 통합 솔루션

void UpdateSwingPhysics(float DeltaTime)
{
    Velocity.Z -= Gravity * DeltaTime;        // 1. 중력
    Position   += Velocity * DeltaTime;       // 2. 위치 업데이트

    FVector ToAnchor = Position - AnchorPoint;
    float   Distance = ToAnchor.Size();

    if (Distance > RopeLength)
    {
        FVector RopeDir  = ToAnchor / Distance;
        float   RadialVel = FVector::DotProduct(Velocity, RopeDir);
        if (RadialVel > 0)
            Velocity -= RadialVel * RopeDir;    // 3. 반지름 속도 제거
        Position = AnchorPoint + RopeDir * RopeLength; // 4. 위치 보정
    }
    Velocity *= SwingDamping;                  // 5. 감쇠
}

Position Correction
에너지 감쇠

문제 1: 단순 중력 적용

로프 제약이 없어 무한히 멀어지는 문제

❌ 문제 상황

  • 중력만 적용하면 캐릭터가 계속 아래로 가속
  • 앵커와의 거리 제한이 없어 무한히 멀어짐
  • 로프가 존재하지 않는 것처럼 동작
  • 빨간 점선 = 로프가 늘어남

✅ 해결 방법

float Dist = (Pos - Anchor).Size();
if (Dist > RopeLength) {
    FVector Dir = (Pos - Anchor) / Dist;
    float RV = Dot(Velocity, Dir);
    if (RV > 0) Velocity -= RV * Dir;
    Pos = Anchor + Dir * RopeLength;
}

핵심 개념

거리 제약: 항상 RopeLength 유지
위치 보정: 거리 초과 시 강제 이동
속도 제한: 바깥 방향 속도 제거
📈

문제 2: 반지름 방향 속도 미제거

나선형으로 바깥으로 퍼지는 문제

❌ 문제 상황

  • 로프가 팽팽해져도 속도 벡터를 그대로 유지
  • 앵커 방향(반지름) 속도 성분이 계속 누적
  • 원운동이 아니라 나선형으로 바깥으로 퍼짐
  • 빨간 벡터 = 반지름 방향 속도 (제거 필요)

✅ 해결: 벡터 분해

FVector Dir = (Pos-Anchor).GetSafeNormal();
float RV = Dot(Velocity, Dir);
FVector RadialComp  = RV * Dir;
FVector TangentComp = Velocity - RadialComp;
if (RV > 0) Velocity = TangentComp;

벡터 분해 원리

반지름 성분 (Radial)
앵커 방향으로의 속도 — 제거해야 원운동 유지
접선 성분 (Tangent)
스윙 방향 속도 — 유지해야 함

왜 내적(Dot Product)?

내적은 한 벡터를 다른 벡터에 투영(projection)한 크기를 계산합니다.

A · B = |A| × |B| × cos(θ)
= A를 B 방향으로 투영한 길이 × |B|

문제 3: 위치 보정 미적용

프레임마다 오차 누적으로 로프가 늘어나는 문제

❌ 문제 상황

  • 속도만 수정하고 위치는 보정하지 않음
  • 프레임마다 미세한 수치 오차가 누적됨
  • 로프 길이가 시간이 지날수록 점점 늘어남
  • "Constraint Drift" 현상이라고 함

✅ 해결: 위치 강제 보정

// 위치 강제 보정 (핵심!)
Position = Anchor + Direction * RopeLength;
// → 항상 정확히 RopeLength 유지

왜 위치 보정이 필요한가?

수치 오차: 부동소수점 연산은 완벽하지 않음
오차 누적: 60FPS × 10초 = 600번 누적
제약 이완: 로프가 늘어나는 비현실적 동작

위치 보정 vs 속도 보정

❌ 속도만 보정:
이미 벗어난 위치는 그대로 → 오차 누적 → Drift
✅ 위치도 보정:
매 프레임 정확한 위치로 강제 이동 → 안정적

문제 4: 감쇠 미적용

에너지가 보존되어 무한히 스윙하는 문제

감쇠 계수: 0.995
빠른 (0.98)느린 (0.999)

❌ 문제 상황

  • 마찰이나 공기 저항이 없는 이상적인 상태
  • 에너지가 보존되어 영원히 같은 속도로 스윙
  • 현실적이지 않은 물리 동작
  • 플레이어가 제어하기 어려움

✅ 해결: 감쇠 적용

// 매 프레임 속도에 감쇠 적용
Velocity *= SwingDamping; // 0.995
// 매 프레임 0.5% 에너지 손실
// → 자연스럽게 멈춤

감쇠 계수 가이드

0.99~0.995: 무거운 로프, 빠르게 멈춤
0.995~0.998: 일반적인 스윙 (권장)
0.998~0.999: 가벼운 로프, 오래 스윙
↔️

속도 벡터 분해

Velocity Vector Decomposition

v (원래) v_r (반지름) v_t (접선) r̂ (로프)

핵심 수식

r̂ = (Anchor - Player) / Distance
v_r = (v · r̂) × r̂
v_t = v − v_r

Dot Product 투영

FVector RopeDir =
  (SwingAnchorPoint - PlayerLocation)
  .GetSafeNormal();

float DotProduct =
  FVector::DotProduct(
    SwingVelocity, RopeDir);

FVector RadialVelocity =
  DotProduct * RopeDir;

물리적 의미

  • v_r: 로프를 따라 움직이는 속도 (제거 대상)
  • v_t: 로프에 수직인 속도 (유지하여 스윙)
  • v = v_r + v_t: 벡터 합성

Sin/Cos 복합 함수 Movement

저비용 고효율 연산을 이용한 AI 이동 패턴

핵심 코드

void AMoveAction::Execute()
{
    float Time = GetWorld()->GetTimeSeconds();
    bool bUseSin = FMath::RandBool();

    if (bUseSin)
        NewLoc.Y += FMath::Sin(Time * Speed)
                    * Amplitude;
    else
        NewLoc.X += FMath::Cos(Time * Speed)
                    * Amplitude;

    Owner->SetActorLocation(NewLoc);
}

파라미터 제어

속도 (Speed): 2.0
진폭 (Amplitude): 50px

장점

  • CPU 연산 비용이 매우 낮음 (하드웨어 최적화)

  • 예측 가능한 패턴으로 디버깅 용이

핵심 코드

bool AEnemyAI::RaycastObstacles()
{
    for (int i = 0; i < 8; i++) {
        float Angle = (i / 8.0f) * TWO_PI;
        FVector Dir = FVector(
            FMath::Cos(Angle),
            FMath::Sin(Angle), 0);

        FVector End = Start + Dir * 200.0f;

        FHitResult Hit;
        bool bHit = GetWorld()
            ->LineTraceSingleByChannel(
                Hit, Start, End,
                ECC_Visibility);

        if (bHit) HandleObstacle(Hit);
    }
}
